hotnews · 热点新闻检索 v1.5.1
=====================================

一、项目说明
以网页形式呈现的国内 / 国际热点新闻图库，支持搜索、分类、筛选、实时刷新。
核心要求：时效性——要闻 / 热榜等时效敏感板块只呈现「当天」的新闻
（更新频率低的垂类按各自窗口放宽，见「四、时效与图片规则」），
且**每条都必须有高清大图**。

二、技术架构
  后端：FastAPI（Python）——抓取 RSS、解析题图、图片代理、翻译、SSR 首屏
  前端：原生 HTML / CSS / JS，明快浅色风格、大字号
  运行：uvicorn，默认 http://localhost:8000
  入口：app.py（选端口 / 开浏览器 / 单实例检测）

  【一句提醒】源在 server.py 的 SOURCES 里登记，不等于一定会出现在页面上：
  没有高清题图的条目（短边 <300）会被自动剔除，对应的源也就跟着从这个栏目里消失。
  所以「某个源看不见」多半不是坏了，而是它这一轮没有合格带图条目。

  【热榜为什么要有中新社·国际这条中文源】
  国际板块其余源全是英文，能否看懂过去完全依赖机器翻译。而免费翻译额度
  一旦被限流，整个板块会当场退回英文（实测某次 120 段只译出 2 段）。
  中新社·国际本身就是中文国际新闻，不依赖任何翻译服务，保证国际热榜
  在任何情况下都读得懂。这类中文条目标记为「已翻译」，后台翻译会跳过，
  不会被拿去做「中译中」翻坏。

  【为什么换源】v1.0.0 用的国内源已大面积停更，但仍返回 200，
  是最初「新闻太旧」的根因。逐源实测（2026-10-06）：

    源                   最新条目       结论
    ------------------  -------------  --------------------
    人民网 politics    2025-06-05     停更 16 个月，已弃用
    人民网 culture     2025-06-05     同上
    新浪新闻          2025-09-23     停更 1 年，已弃用
    网易新闻头条       无条目         已废弃
    央视网 / 环球网    无条目         已废弃
    澎湃 / 36氪        无条目         已废弃
    中国网             404            已下线
    中新网（8 频道）   当天凌晨       在用（无题图）
    界面新闻           当天凌晨       在用（有题图）
    IT之家             当天凌晨       在用（有题图）

  结论：国内综合类 RSS 生态基本已死，现役可用源只剩中新网系 +
  少数科技 / 财经垂类站。中新网文字稿不配图，故部分卡片为
  品牌色块 + 分类字的排版形式（见「六、界面说明」）。

  【v1.1.1 图片质量修复】
  1) 界面新闻 RSS 把图片 URL 写死成站方默认图（日期停在 2022 年），
     30 条里只有 12 张唯一图、两张各重复 10 次 / 9 次，属于「张冠李戴」。
     现在按两条规则清洗：URL 日期比文章旧 180 天以上 → 判占位图丢弃；
     同一源被 3 条以上新闻共用 → 判默认图丢弃。
  2) 部分 RSS 图片 URL 带畸形协议前缀（如 https:https://...），
     之前会拼成 https://www.jiemian.com/https:... 全部加载失败，
     现已归一化处理。
  3) 图片代理补 Referer 头，以符合源站的访问策略（部分 CDN 会校验来源站点）。

四、时效与图片规则（v1.5.1）
  时效常量都在 server.py 里定义（改之前先读旁边的注释，每个值都有实测依据）：
    MAX_AGE_HOURS = {"cn": 24, "intl": 48}     采集窗口：国内 24 小时 / 国际 48 小时
    SAME_DAY = True                            要闻 / 热榜等时效敏感栏目只留「当天」
    FALLBACK_MIN = 8                           某板块当天不足 8 条 → 回退到最近 24 小时，
                                               免得凌晨打开是空页
    CLS_MAX_AGE_HOURS = {"科技": 96, "软件": 120, "娱乐": 120,
                         "国际娱乐": 120, "热榜": 24}
                                               垂类按各自窗口放宽 —— 只按当天筛，会把更新
                                               频率低的垂类源整个饿死（软件栏只剩一家）
    FRESH_MIN_PER_CLS = 6 / FRESH_MIN_SITES = 3
                                               「当天优先」的两个下限：某栏目当天条目不足
                                               6 条、或不足 3 家网站，才允许补进较旧的条目
  作用：某个源哪天悄悄停更，页面不会再拿旧闻充数；超窗口的条目直接丢弃，日志记录滤除条数。

  图片：MIN_IMG_SHORT_SIDE = 300 —— 每条新闻必须有高清大图（短边 ≥300），无图一律不上。
  国内热榜三家（澎湃 / 红星 / 凤凰）本身是纯文字榜，会去文章页抓 og:image 补齐；
  RSS 本身不带图的源（少数派 / 新浪娱乐）同样去文章页取 og:image。

  绝不伪造时间：解析不出发布时间的条目 published 记为 0，不参与「当天」列表，
  界面显示「时间未知」。早期版本曾把「解析不出时间就当刚刚」，
  导致旧闻被排到热榜第一条，已彻底删除。

五、功能清单
  · 国内 / 国际 切换
  · 搜索：标题 + 描述关键词（输入防抖 260ms）
  · 分类：全部 / 要闻 / 国内 / 国际 / 科技 / 软件 / 社会 / 体育 / 娱乐
    （选项按实际抓到的内容动态生成；财经、文化已因无源移除）
  · 筛选：最新优先 / 最早优先
  · 时间显示：「3 小时前 · 10-06 02:46」相对 + 绝对双显示
  · 刷新按钮 + 每 60s 版本号轮询
  · 图片经 /img 代理（服务端按源站要求带请求头获取，来源站点可正常返回图片）
  · 首屏 SSR：页面 HTML 直接带 60 条，打开即有内容
  · 退出程序按钮：页面右上角（见「七」）

六、界面说明
  条目一律是图片卡（190px）：每条新闻都带高清题图，没有合格题图的条目不上页面。
  「品牌色块 + 分类字」的占位卡是早期版本的做法，v1.5.1 起不再产生这种卡片
  （前端还留着这套样式作为兜底，正常抓取流程下用不到）。

  【关于图片清晰度】图片由各源站决定，代理是纯透传不压缩：
  IT之家原图最大 1600×900，界面新闻固定 580×330 缩略图。
  若某条图看起来小/糊，是源站本身给的尺寸，非本程序压损。

七、运行方式
  【单文件版（推荐）】
    双击「热点新闻.exe」即可，无安装、无控制台窗口、无伴随文件。
      · 自动选端口（8000 起往后找，被占则顺延至 8014）
      · 服务就绪后自动打开浏览器
      · 已在运行时双击，不会起第二个进程，直接把浏览器指向已有实例
      · 退出：页面右上角「退出程序」→ 确认即可
      · 日志：exe 同目录 hotnews.log（超过 1MB 自动滚动为 .old）
    可选：把 config.json 放在 exe 同目录可改翻译后端，不放就用默认。

  【源码版（需系统 Python 3.8+）】
    1) pip install -r requirements.txt
    2) python app.py
    3) 浏览器打开 http://localhost:8000

八、自动更新（v1.2.0 新增，v1.2.1 修复）
  · 启动时后台静默检查新版本（约 5 秒后，不阻塞使用）
  · 发现新版 → 自动下载 → 校验 sha256 → 退出时自动替换并重启
  · 页面右上角「检查更新」按钮可手动触发
  · 更新源：Gitee（国内下载稳定，约 1.4MB/s）
    https://gitee.com/kele551/hotnews
  · 关闭自动更新：config.json 里把 update.enabled 改成 false
  · 检查失败（无网络）静默忽略，不影响正常使用
  · v1.2.1 修复：替换 exe 时不再弹黑窗（改用 PowerShell 隐藏执行）；
    检查更新不再卡住（直连 + 非阻塞 + 前端超时）

九、翻译后端配置
  国际新闻源为英文，可配置翻译为中文。编辑 config.json：
    backend: mymemory（免费免 key，默认兜底）/ baidu（需 appid + secret）
             / deepl（需 auth_key）
  实测：mymemory 可用，例如
    "Global markets rallied today" -> "全球市场今日反弹"

  【额度限制（重要）】mymemory 匿名每 IP 每天约 5000 词；在 config.json
  的 contact 里填一个邮箱可提到约 50000 词/天。额度当天累计用尽会返回
  429 / "MYMEMORY WARNING"，此时整批熔断（不会逐段傻等重试），
  条目保留英文原文且**不写入缓存**，次日额度自动恢复后会重新译出。

  译不出的部分怎么办：翻译结果带磁盘缓存（~/.hotnews/trans_cache.json
  之类），翻过的不会再消耗额度。日常使用增量很小，主要是首次运行
  或源大幅更新时消耗多。另外国际热榜已含中文源，见「三、数据源」。

十、打包
  python build.py                                   # 源码包 + 绿色版 zip
  python make_icon.py                               # 重新生成图标
  pyinstaller build_exe.spec --clean --noconfirm    # 单文件 exe（约 14 秒）
  注意 build_exe.spec 里 console=False（不弹黑窗）；
  改成 True 可恢复控制台观察启动过程。

十一、已知取舍
  · 本副本早期按「热点新闻检索 · 项目说明」文档重建，现已接管
    Gitee 仓库 https://gitee.com/kele551/hotnews.git（已转公开）作为
    更新源，GitHub 为镜像（https://github.com/kele551/hotnews）。
  · httpx 走 trust_env=False 直连：环境里的代理会让 RSS 抓取从
    0.1s 劣化到约 20s，因此全程绕开代理。
  · 启动时后台预热两个 Region，首屏打开即见数据（约 8s 内就绪）。
  · 单文件 exe 每次启动要解包到 %TEMP%，首次打开慢 1-2 秒，属正常。
  · 无控制台窗口，故致命错误（如端口全被占用）改用系统对话框提示。
  · check_sources.py 是数据源自检脚本，排查「某个源怎么没内容」时用：
      python check_sources.py
    会打印每个 Region 的条数、最新 / 最旧时间、带图数量、分类分布。
