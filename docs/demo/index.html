热点新闻检索 hotnews · 演示视频

单文件 Windows 新闻聚合工具 —— 首屏 2~3 秒出内容，国内与国际按源站栏目分流
时长 1 分 58 秒　·　文件大小 6.6 MB　·　格式 MP4（H.264），手机与电脑浏览器均可直接播放
关于本项目
  • 单文件 exe，双击即用，不用安装、不需要管理员权限
  • 两阶段抓取：首屏 2~3 秒出内容；每条保留原文跳转，不存储、不转载正文
  • 按源站栏目分类做国内 / 国际分流；本地自绘桌面通知，不依赖系统通知
  • 在线升级带签名校验，校验不过一律拒绝、保留旧版本
