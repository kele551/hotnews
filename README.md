## 使用

下载 [最新 Release](https://gitee.com/kele551/hotnews/releases) 里的 `hotnews-v1.5.4.exe`，双击运行，自动打开浏览器。

- 自动选端口（8000 起，被占则顺延）
- 启动时自动检查更新（可关闭，见 `config.json`）
- 页面右上角「检查更新」手动触发
- 右下角气泡提醒（见下文），点气泡可直接打开对应新闻

> 国内用户请从 Gitee 下载（速度快）。GitHub 仓库为镜像。

<details>
<summary>📦 <b>关于本次安装包的小公告</b>（点开看）</summary>

> **本次更新了安装包，但版本号没有变。**
> 升级检查是拿「线上版本号」和「你本地的版本号」比的 —— 版本号没变，
> **已经装着同一个版本号的朋友不会收到升级提示**；比线上旧的版本仍会正常自动升级。
> 如果你用着不顺畅（例如**国际板块里混进了国内新闻**），
> 可以**重新下载最新安装包**覆盖安装一次，你的配置与收藏都会保留；更新内容以发行页说明为准。
>
> 最新安装包里，**国际板块的国别判定按「先看是不是国内主体，再看有没有具体的国际信号」重做**，

> 仓库源码的同步会随后统一提交。

## 设计要点

<details>
<summary><b>分流 / 时效 / 图片 / 气泡提醒</b>（点击展开）</summary>

**国内 / 国际怎么分**：用站方自己的栏目分类（凤凰网文章页 JSON-LD 的 `articleSection` 等），不靠猜关键词；
认不出才退回关键词判定（必须「像国际**且**不像国内」才算，避免把官方表态误判成国际新闻）。
`articleSection` 只决定国内还是国际，不参与栏目命名。

**时效规则**：

- 头条 / 热榜严格当天（热榜给 24 小时）；垂类（科技 / 软件 / 娱乐）按各自窗口放几天，避免低频源被饿死
- **绝不伪造时间**：解析不出就丢弃，时间一律取自源站或文章页的真实发布时间

**图片规则**：

- 每条必须有高清大图（短边 ≥ 300），无图不上
- RSS 不带图的源自动去文章页取 `og:image` 或按站方规则取正文首图（单条限时 3 秒、元数据缓存 7 天，取不到跳过该条）
- 列表页只给缩略图的源，按站方 URL 规则改写成原图地址

**右下角气泡提醒**：自绘窗口，**不依赖系统通知**。一组滚动播放 10 条、每条 5.6 秒，标题尾部带 `(3/10)` 进度；
第一行显示栏目（头条有专属红色样式、热榜条目带出处、国际条目带频道前缀）；
名额按栏目配额：头条 2 + 科技 2 + 财经 2 + 娱乐 2，其余按 软件 → 热榜 → 国际 补足；
同一来源只取一条、只播中文条目、播过的不重复。
新闻更新 10 分钟最多弹一次；「大事」（标题命中关键词或 ≥3 家来源同报）与「★ 我的软件被发布」即时弹、不节流。
鼠标悬停暂停倒计时并浮出「打开 / 退出」，点气泡正文或「打开」直接打开当前新闻原文。

## 自动更新

- 默认**全自动、不弹确认框**：启动后静默检查 → 静默下载 → **Ed25519 验签 + sha256 / 尺寸校验** → 自动替换重启
- 只有出问题才提示一次（说明原因 + 怎么办）；**旧版本始终可用**，替换失败可回退，程序不会消失
- 升级源依次尝试：Gitee raw ×2 → GitHub raw（兜底），三处均须验签通过才被采用
- 开关在 `config.json`（可被 `%LOCALAPPDATA%\hotnews\config.local.json` 覆盖）：

```json
{ "update": { "enabled": true, "auto_update": true } }
```

> 维护者发布流程与 `version.json` 相关的踩坑清单，见 [CONTRIBUTING.md](.github/CONTRIBUTING.md) 第八节。

## 路线图（Roadmap）

1. **继续补实测可用的源** —— 按「真连通 + 带图（短边 ≥300）+ 有当天或近日内容」补，目标每栏稳定 ≥3 家
   （当前缺口：国内财经 2 家、国内娱乐 3 家）
2. **移动端局域网查看** —— 为小屏做自适应布局，并把「只读浏览」与「本机管理」在界面上分清
   （现状与权限边界见 [SECURITY.md](.github/SECURITY.md)）
3. **源可用性自检面板** —— 把 `check_sources.py` 搬进页面，一眼看出哪个源抓不到、不带图、停更

> 维护原则：**不为修 bug 单独发版**（修复攒到下一个功能版本一起发）；**没测过的东西不交付**。详见 [CONTRIBUTING.md](.github/CONTRIBUTING.md) 第五节。
